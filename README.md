# pdm2026d-equipo-03-soundwave

## 📌 Problema
Interrupciones constantes por anuncios publicitarios, incapacidad para filtrar o bloquear canciones no deseadas en listas automáticas y alto consumo de datos móviles al escuchar música durante la rutina diaria de los estudiantes.

## 👤 Usuario Primario
Estudiantes universitarios que escuchan música durante sus actividades diarias (estudiar, viajar en transporte público o hacer tareas) y buscan una alternativa gratuita para acceder a su música sin interrupciones ni dependencia de internet.

## 🔄 Flujo del MVP
**Inicio** (Pantalla principal) ➔ **Acción 1** (Buscar/Descargar canción o lista) ➔ **Acción 2** (Omitir o bloquear pista no deseada) ➔ **Resultado** (Reproducción continua offline sin anuncios).
